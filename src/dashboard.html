    MNIST · digit classification
    A trained convolutional network takes a 28 × 28 grayscale image and scores digits 0–9. Use it to explore classification, compare predictions across devices, and see how handwriting style affects mistakes. Scores are relative model outputs and can be high on bad inputs.
    
      
    Synthetic convolution · feature maps
    Three fixed-weight graphs use 32, 64, or 128 pixel square inputs and produce 16, 32, or 64 channels. Their filters show how different parts of a drawing trigger activation. The heatmap shows the channel with the highest average activation, scaled to its own peak. These graphs have no learned labels.
    
      
    Bring your own model
    The CLI benchmarks local ONNX and OpenVINO IR models with synthetic inputs. Manual tests use task-specific input preparation and output decoding. Text generation, transcription, embeddings, and object detection each need a dedicated adapter.
